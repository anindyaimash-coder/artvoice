📲 3. CARA INSTALL JADI APLIKASI DI HP & LAPTOP (TANPA RIBET)
--------------------------------------------------------------------
Agar ArtVoice muncul sebagai ikon aplikasi mandiri di layar utama HP atau Dock Laptop Anda (bisa dibuka walau sedang offline):

📱 DI HP ANDROID (Chrome):
1. Buka link https://anindyaimash-coder.github.io/artvoice/ di Google Chrome.
2. Masukkan Kode Akses di atas.
3. Ketuk tombol "📲 Install App" di pojok kanan atas (atau ketuk menu titik tiga Chrome ⋮ lalu pilih "Install App / Tambahkan ke Layar Utama").

🍎 DI IPHONE / IPAD (Safari):
1. Buka link https://anindyaimash-coder.github.io/artvoice/ di Safari.
2. Ketuk ikon "Share" (kotak dengan panah ke atas di bagian bawah layar).
3. Pilih "Add to Home Screen (Tambahkan ke Layar Utama)".

💻 DI LAPTOP WINDOWS / MAC:
- Pengguna Chrome / Edge / Brave: Klik tombol "📲 Install App" di pojok kanan atas halaman, atau klik ikon Install di ujung kanan kolom URL.
- Pengguna Safari Mac: Klik menu File -> Add to Dock... (Tambahkan ke Dock) di pojok kiri atas layar Mac.
