Pasang ArtVoice Jadi Aplikasi

Agar ArtVoice muncul di Dock Mac, Desktop PC, atau Layar Utama HP Anda tanpa bar browser:

💻 Di Mac (Safari):

Klik menu File → Add to Dock... (Tambahkan ke Dock) di pojok kiri atas layar Mac Anda, atau klik ikon Share di kanan atas Safari lalu pilih Add to Dock.

🌐 Di Chrome / Edge / Brave (Laptop & Android):

Klik ikon Install (layar dengan panah bawah) di ujung kanan kolom alamat URL (address bar), atau buka menu titik tiga ⋮ → Cast, save, and share → Install page as app.

📱 Di iPhone / iPad (Safari):

Ketuk tombol Share di bagian bawah layar → pilih Add to Home Screen (Tambahkan ke Layar Utama).
